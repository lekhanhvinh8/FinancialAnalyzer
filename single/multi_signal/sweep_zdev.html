z_dev sell gate: stat window × threshold

50 symbols, 6×11 = 66 cells plus an off cell, 6.5 min. The gate is OFF in config, so every comparison is against off — there is no live cell for this grid.
It blocks a sell while z_dev is at or BELOW the threshold, the opposite polarity to the two momentum gates: a higher value blocks MORE and sells LESS. Thresholds are raw — z_dev is a z-score and its spread is flat across stat windows (p95 = 2.218 × w0.009, R² = 0.27; p5 −2.30, p50 −0.15, p95 +2.31, wider than a unit normal).
Start is fixed at 1000 + 400 for every cell — what the window cap buys. The old 700 would put it at 1700 and take back the 12 symbols that got this gate switched off.

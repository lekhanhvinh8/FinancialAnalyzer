P/E sell gate — SELL_MIN_PELOG

52 symbols, 16 thresholds plus OFF, 2.2 min. Blocks a sell while ln(P/E / median P/E over 500 bars) is at or below the threshold — while the P/E is not stretched. Higher blocks more.
Every figure is paired per symbol against OFF, which is what config has. OFF runs on the same start index as the gated cells, so it is not judged on extra bars.
Read the prior, not the table. This is the same shape of gate as SELL_MIN_ZDEV, which lost on all 66 of its cells. The one real difference is that z_dev is computed from price alone while this can see earnings.

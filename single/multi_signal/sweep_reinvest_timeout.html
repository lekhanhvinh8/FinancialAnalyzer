The valve also fires the very first time there is anything in the reserve, on any setting above zero, because "has never sold" satisfies its condition. 0 removes the valve and that free first release together.
It competes with PERCENT_REINVEST: a short timeout empties the reserve before the price condition can act, a long one leaves the condition doing the work. Watch reinv for which is happening.

Click any row to make it the reference — the vs column recomputes against it from the per-symbol numbers. That is the only way to compare two settings: subtracting two vs values would be median(A−ref) − median(B−ref), the same mistake one level up.
median, win and worst must never be subtracted between rows. The symbol at the median of one column is a different symbol from the one at the median of another, because changing the threshold reorders the ranking — on this grid that mistake reads +5.51 for a cell that is worse for 33 of 48 symbols. mean is the exception and may be subtracted: it is linear, so mean(A)−mean(B) is exactly mean(A−B). vote is already a pairwise round robin.
Green marks the best cell in each column. mean is hostage to the largest symbol, vote gives each symbol one vote and is blind to size. reinv is the mechanism check: if it barely moves across the grid, the timeout is doing the work and this parameter only shifts timing.
